Вход администратора

Войдите через Firebase Authentication. Доступ проверяется по users/{uid}.role = admin.

Панель проверяет вход и users/{uid}.role = admin перед показом данных и перед удалением. Обязательно должны быть настроены Firestore Rules, запрещающие не-админам читать и изменять эти данные: проверка в HTML сама по себе не является защитой базы.
